# Onboarding Modular Character Asset Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `writing-plans` before implementation and `imagegen` for raster reference generation. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a reusable pixel-character base for onboarding with male and female adult mannequin variants, animated base poses, swappable fashion categories, and fashion-set expressive poses aligned with `plans/ai-npc-plan/implementation-plan.md` Nala states.

**Architecture:** Assets use a fixed transparent `96x128` canvas so base frames and clothing layers align without per-item adjustment. Image generation creates art-direction references; the production preview assets are generated by a deterministic Pillow script so every layer has identical dimensions, predictable frame counts, and can be validated programmatically.

**Tech Stack:** Built-in `image_gen` for reference images, Python + Pillow for aligned PNG generation, static HTML/CSS/JS for mockup animation, Playwright Core + Google Chrome for screenshot validation. No npm dependency changes.

## Asset Contract

- Canvas: `96x128`, transparent PNG, `image-rendering: pixelated`.
- Base body: adult, bald, non-sexual mannequin, minimal neutral undergarment/base layer. No explicit nudity.
- Base variants: `male`, `female`.
- Pose/view matrix:
  - Idle standing: `front`, `back`, `side`, 4 frames each.
  - Walk: `front`, `back`, `side`, 4 frames each.
  - Sitting: `floor`, `chair`, 4 frames each.
- Expressive pose matrix, following Nala state coverage in `plans/ai-npc-plan/implementation-plan.md`:
  - `idle`, `thinking`, `happy`, `confused`, `greeting`, `pointing`.
  - Generated for both gender bases and as precomposed fashion-set frames under `assets/poses/{gender}/{set}/{pose}/frame-00..03.png`.
  - Detailed image-generation versions are extracted from source sheets into `assets/detail/poses/{gender}/{set}/{pose}/frame-00..03.png` and used as the primary showcase sprites.
- Fashion categories:
  - `hair`
  - `face-accessory`
  - `expression`
  - `shirt`
  - `body-accessory`
  - `pants`
  - `shoes`
- Theme sets:
  - `field-researcher`: practical outdoor/research set.
  - `campus-organizer`: warm leadership/campus set.
  - `night-coder`: quiet technical/coder set.
- Independent items:
  - Hair: `short-crop`, `side-part`, `low-bun`.
  - Face accessory: `round-glasses`, `half-mask`, `mustache`.
  - Expression: `calm`, `happy`, `focused`.
  - Shirt: `plain-tee`, `pixel-hoodie`.
  - Body accessory: `satchel`, `lanyard`.
  - Pants: `utility-pants`, `shorts`.
  - Shoes: `boots`, `sneakers`.
