- a non-empty, route-specific title and description;

- `index, follow` on public pages;
- an absolute Open Graph image URL;
- a `summary_large_image` Twitter card and image URL.

The checked published Blog entry has `og:type=article` and its own canonical
URL. The forbidden page emits `noindex`, and an anonymous `/manage` request
returns HTTP 307 to `/forbidden?reason=login`.
