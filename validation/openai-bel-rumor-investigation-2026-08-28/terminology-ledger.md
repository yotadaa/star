# Terminology ledger

| Term | Meaning supported by the checked record | What must not be inferred |
|---|---|---|
| Bel | A codename asserted by `@synthwavedd` in a 26 August 2026 X post for an alleged completed OpenAI pretraining run. | The codename, run, architecture, capability, or completion is not publicly confirmed by OpenAI. |
| Doug | An alleged internal predecessor named in the same post. | No checked OpenAI source identifies Doug or connects it to Astra or GPT-6. |
| Astra | OpenAI's public name for an internal model it called its “next major model” on 1 August 2026 and an “upcoming” model on 18 August. | Astra's public record does not establish that it is GPT-6, uses Doug, derives from Bel, or has a public release date. |
| GPT-6 | A future-model label used in the rumor and earlier social speculation. | No checked first-party record establishes the rumored Doug/Astra/GPT-6 lineage. |
| GPT-4.5 size class | A social-post comparison to the alleged Bel run. OpenAI described GPT-4.5 as its largest GPT model at release and as compute intensive. | “Size” cannot be converted into a parameter count: OpenAI did not publish the relevant count, architecture, active parameters, or a comparable Bel measurement. |
| `>10T total parameters` | The exact scale claim in `@synthwavedd`'s post. | It is not a token count, training-compute figure, verified architecture, or measured value. The later “10T+ pretrain” paraphrase is less precise. |
| Pretraining | The broad training stage before task-specific post-training or reinforcement learning. | Saying a pretrain finished does not establish a deployable model, product date, safety readiness, or post-training status. |
| Reinforcement learning / RL | OpenAI's public 18 August update discusses frontier RL runs and says its largest planned frontier RL run remained on hold at that time. | That statement does not identify Doug or Bel and does not prove or disprove a separate pretraining run. |
| Post-GPT-6 base | A role assigned to Bel by the social source. | It is not an official OpenAI roadmap term in the checked record. |
| AGI threshold | Undefined rhetoric in the source post about a possible future model. | It has no measurement, capability test, or OpenAI definition attached to the Bel claim. It must not be presented as a technical milestone. |
| Stargate | OpenAI's large US AI-infrastructure initiative with infrastructure and investment partners. Some announced capacity is planned; some Abilene capacity has run early training and inference workloads. | Infrastructure availability does not identify which secret model used it, prove Bel exists, or prove a particular run completed there. |
| Public answer / competitive answer | The rumor author's loose description of whether Anthropic can match an unreleased Astra. | There is no common benchmark, public Astra access, or named internal statement that makes this a measurable comparison. |
| Corroboration | Independent strong evidence that establishes the same proposition. | Reddit screenshots, Adit's paraphrase, and articles derived from Leo's post are repetitions of one source chain, not corroboration. |
