# Terminology ledger

| Istilah | Arti dalam artikel |
|---|---|
| WebMCP | Proposal API browser agar website mendaftarkan tool terstruktur |
| MCP | Protokol client-server untuk menghubungkan aplikasi AI dengan tool/data eksternal |
| Tool imperatif | Tool JavaScript yang ditopang logika aplikasi |
| Tool deklaratif | Tool yang dideskripsikan melalui anotasi HTML/form |
| Discovery | Tool tersedia setelah client kompatibel mengunjungi halaman |
| Screen scraping | Menebak kontrol/state dari pixel atau interaksi DOM |
| Read-only | Mengembalikan data publik terbatas tanpa mengubah state server |
