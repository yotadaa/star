# SEO intent and SERP gap

## Primary intent

The article answers a comparative implementation query: `free portfolio stack Next.js Convex Cloudflare R2 Vercel`.

It does not compete head-on with broad template listicles for `free portfolio website`. The narrower intent combines four decisions that current results treat separately: framework, deployment, reactive data, and billable object storage.

## Search snapshot

- The exact four-service query returned official Next.js + Convex templates, Vercel-versus-Cloudflare comparisons, forum discussions, and generic portfolio starters. No inspected result answered the complete free-limit and billing question in one page.
- The generic Next.js portfolio query was crowded with tutorials and template collections. A new generic walkthrough would add little.
- The Next.js + Convex + R2 query led with Convex quickstarts and a Vercel template, but did not explain why R2 belongs beside Convex file storage, when it does not, or why R2's free allocation still begins with checkout.

## On-page plan

- Slug: `free-portfolio-stack-nextjs-convex-r2-vercel`
- Visible title: `A Portfolio Stack That Can Stay at $0: Next.js, Convex, R2, and Vercel`
- SEO title: `Free Portfolio Stack: Next.js, Convex, R2, and Vercel`
- Primary phrase appears once in the SEO title and naturally in the opening answer.
- The opening answers the price question and separates free infrastructure from the external cost of buying or renewing a production domain.
- A provider-limit table gives a directly scannable answer.
- Descriptive H2s cover architecture, free limits, payment setup, build steps, pros, cons, and the simpler static alternative.
- Original project analysis supplies experience beyond provider-page paraphrase, including the production custom-domain boundary for R2 media.
- Adjacent links point to first-party sources.
- The live route already supplies canonical metadata, `BlogPosting` JSON-LD, author identity, descriptive image alt text, related-article links, sitemap discovery, and IndexNow notification.

## Ranking boundary

No position is promised. Google says its systems prioritize helpful, reliable, people-first content; Bing says SEO does not guarantee rankings. The work can improve relevance, originality, crawlability, and evidence quality, then measure impressions and indexation after publication.
