# Terminology ledger

| Term | Meaning used in the article |
|---|---|
| WebMCP | Proposed browser-facing API for websites to register structured tools |
| MCP | Client-server protocol for connecting AI applications to external tools and data |
| Imperative tool | JavaScript-registered tool backed by application logic |
| Declarative tool | Tool described from HTML/form annotations |
| Discovery | Tool availability after a compatible client visits a page |
| Screen scraping | Inferring controls and state from pixels or DOM interaction |
| Read-only | Returns bounded public data without changing server state |
