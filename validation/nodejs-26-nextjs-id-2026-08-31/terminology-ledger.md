# Terminology ledger

| Istilah | Arti dalam artikel |
|---|---|
| Current | Lini Node.js yang masih berada pada fase pengembangan fitur, belum LTS |
| Active LTS | Fase dukungan yang disarankan Node.js untuk produksi |
| Kompatibilitas build | Kemampuan proyek memasang dependensi dan dikompilasi |
| Kompatibilitas runtime | Perilaku jalur produksi setelah server berjalan |
| Probe kompatibilitas | Pemeriksaan terbatas untuk menemukan kegagalan jelas, bukan benchmark |
| Node di Workers | Kompatibilitas tooling build, bukan runtime Node server penuh |
