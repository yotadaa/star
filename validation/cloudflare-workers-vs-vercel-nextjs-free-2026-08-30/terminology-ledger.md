# Terminology ledger

| Term | Accepted meaning | Direct source | Rejected alternative | Article wording |
|---|---|---|---|---|
| Workers Free | Cloudflare's no-cost Workers plan with 100,000 Worker requests per day and 10 ms CPU per HTTP invocation. | https://developers.cloudflare.com/workers/platform/limits/ | Unlimited free server compute. | `Workers Free` |
| Static Assets | Files served by Cloudflare's static asset layer; those requests are free and unlimited unless routing invokes the Worker first. | https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/ | Every asset request consumes the 100,000 Worker-request allowance. | `Cloudflare Static Assets` |
| CPU time | Time actively executing code; network, KV, or database waiting is not CPU time. | https://developers.cloudflare.com/workers/platform/limits/#cpu-time | Wall-clock request duration. | `active CPU time` |
| Vercel Hobby | Vercel's no-cost plan for non-commercial personal use, with separate monthly resource allowances. | https://vercel.com/docs/plans/hobby | A free commercial hosting plan. | `Vercel Hobby` |
| Edge Request | A request handled by Vercel's CDN; static assets and functions both incur CDN Requests shown as Edge Requests. | https://vercel.com/docs/manage-cdn-usage#cdn-requests | A function invocation only. | `Vercel Edge Request` |
| Fluid compute | Vercel's function model that meters active CPU, provisioned memory, and invocations separately; I/O waiting is not active CPU. | https://vercel.com/docs/functions/usage-and-pricing | A single wall-clock function-duration allowance. | `Fluid compute` |
| vinext | A beta Vite plugin that reimplements the Next.js API surface, with Cloudflare Workers as its primary deployment target. | https://developers.cloudflare.com/workers/framework-guides/web-apps/nextjs/; https://github.com/cloudflare/vinext | The official Next.js compiler running unchanged on Workers. | `vinext` |
| OpenNext | A community adapter that transforms standard `next build` output for platforms including Workers. | https://developers.cloudflare.com/workers/framework-guides/web-apps/opennext/ | Cloudflare's current default path for new Next.js applications. | `OpenNext adapter` |
| Native Next.js | In this article, deployment through Vercel's zero-configuration Next.js integration maintained alongside the framework. It is not a claim that other adapters use private APIs. | https://vercel.com/docs/frameworks/full-stack/nextjs; https://nextjs.org/docs/app/guides/deploying-to-platforms | A proprietary Next.js runtime that makes other platforms invalid. | `Vercel's first-party Next.js integration` |
| Worker and function bundle size | Cloudflare measures a Worker's 3 MB limit after gzip compression; Vercel's standard 250 MB Function limit is uncompressed. Both include server code and imported files, but the differently measured figures are not directly comparable to repository size. | https://developers.cloudflare.com/workers/platform/limits/#worker-size; https://vercel.com/docs/functions/limitations | One shared compression basis, repository size, or total static-output size. | `3 MB compressed Worker` and `250 MB uncompressed function` |
