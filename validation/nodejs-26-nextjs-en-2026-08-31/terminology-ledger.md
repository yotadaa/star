# Terminology ledger

| Term | Meaning used in the article |
|---|---|
| Current | Node.js release line under active feature development, not yet LTS |
| Active LTS | Production-oriented support phase recommended by Node.js |
| Build compatibility | Whether the project installs and compiles under a runtime |
| Runtime compatibility | Whether production paths behave correctly after startup |
| Compatibility probe | One bounded pass used to expose obvious failures, not rank performance |
| Node compatibility in Workers | Build-tool compatibility; not equivalence to a full Node server runtime |
