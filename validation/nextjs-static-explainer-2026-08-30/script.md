# Static content script — What is Next.js?

## Production target

- Format: one 16:9 static poster, rendered at 1920×1080.
- Audience: a React beginner deciding what belongs in a portfolio stack.
- Single job: explain what Next.js adds around React without implying that it provides hosting, a database, or file storage.
- Reading time: under ten seconds for the main statement; the supporting diagram may take another ten.

## Factual spine

The official documentation defines Next.js as a React framework for full-stack web applications. React components build the interface. Next.js adds application structure and production tooling around those components, including routes, server and client rendering boundaries, data handling, bundling, compilation, and web optimizations.

Next.js does not require Vercel, and it is not a database or an object store. Those are separate architecture choices.

## Visual script

The poster reads from left to right like a physical workshop diagram. A stack of loose paper interface components enters a compact routing press. The press stamps one clear route into the work, divides server work from browser work, and sends a complete application sheet out the other side.

The machinery is a metaphor, not a product screenshot. Exact technical wording stays in HTML so every letter remains sharp. The generated illustration contains no labels, logos, code, or fake interface text.

## Art direction locked before asset generation

- Palette: carbon `#151714`, old paper `#E9DFC5`, muted steel `#7F857D`, ink blue `#345D62`, safety orange `#C75A2A`.
- Display type: `Arial Narrow`, `Liberation Sans Narrow`, or the nearest installed condensed sans-serif.
- Body and labels: `IBM Plex Mono`, `DejaVu Sans Mono`, or the nearest installed monospace.
- Layout: left-aligned statement in the upper-left; generated routing press across the lower middle; input and output annotations follow the machine's real direction.
- Signature: a physical selector plate on the press carries the three framework jobs as deterministic HTML labels.
- Avoid: framework-logo worship, terminal screenshots, code rain, neon, glass panels, gradients, floating UI cards, fake text, and extra provider logos.

## Asset derived from this script

Generate exactly one text-free raster illustration:

- A believable mechanical routing press photographed on a dark workshop surface.
- One input tray at left containing several blank component cards.
- One central press with a circular selector and three physical indicator slots.
- One output tray at right containing a single finished page-shaped sheet.
- Soft directional light, restrained colors, visible paper fiber, scuffed metal.
- Wide composition with clean negative space above and below for the locked copy.
- No text, letters, numbers, logos, people, screens, code, or watermark.

All remaining elements must be rendered in HTML/CSS. No second generated asset is required.
